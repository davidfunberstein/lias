🔵 כניסה למערכת עם חשבון Google
איך משיגים Client ID? (הוראות מדויקות)
1. פתח console.cloud.google.com → צור פרויקט (או בחר קיים).
2. תפריט → APIs & Services → Credentials.
3. Create credentials → OAuth client ID.
4. אם מבקשים "Configure consent screen": בחר External, App name: LIAS, והזן את המייל שלך כ-User support email וכ-Developer contact. שמור.
5. חזור ל-OAuth client ID → Application type: Web application → Name: LIAS.
6. תחת Authorized JavaScript origins הוסף בדיוק: http://localhost:8500
7. Create → העתק את ה-Client ID (מסתיים ב- .apps.googleusercontent.com) והדבק כאן.
הערה: את ה-Client secret אין צורך — האימות נעשה מול Google בצד השרת.
🔐 Google Authenticator (קוד TOTP) — חלופה מהירה ל-OTP במייל
מה זה ומאיפה משיגים את הסוד? (הוראות)
למה זה משמש: (א) כניסה למערכת LIAS עצמה — כשמוגדר סוד, מסך הכניסה ידרוש קוד בן 6 ספרות, וכל כניסה תירשם ביומן ההתחברויות; (ב) אם ההזדהות שלך ב-gov.il מוגדרת עם אפליקציית אימות — בחר למעלה "Google Authenticator" והמערכת תחשב את הקוד לבד במקום להמתין למייל.
איך מייצרים סוד:
1. פתח את אפליקציית Google Authenticator בטלפון → + → הזנת מפתח התקנה (Enter a setup key).
2. שם החשבון: הקלד LIAS — כך תזהה אותו ברשימה.
3. במפתח (Key) הקלד מחרוזת base32 משלך (אותיות A–Z וספרות 2–7, 16–32 תווים) — או הדבק כאן סוד קיים שקיבלת מ-gov.il.
4. הדבק את אותו סוד בשדה למעלה ולחץ 💾 שמור. (נשמר ב-Keychain בלבד.)
הקוד מתחלף כל 30 שניות; המערכת מקבלת גם קוד מהחלון הקודם (סטיית שעון).
🛡️ יומן התחברויות (מי מתחבר, מתי, ומה התוצאה)
כל ניסיון התחברות נרשם. שתי התחברויות לאותו פורטל לא ירוצו במקביל (מונע OTP כפול).

חיבור ל-gov.il — נשמר ישירות ב-Keychain של המחשב

📧 חשבון המייל שמקבל את קוד האימות מ-gov.il
איך משיגים סיסמת אפליקציה של Gmail? (הוראות)
1. היכנס לחשבון Google → ניהול החשבון → אבטחה.
2. הפעל אימות דו-שלבי (2-Step Verification) — בלעדיו Google לא מציג סיסמאות אפליקציות.
3. פתח myaccount.google.com/apppasswords (או חפש "סיסמאות אפליקציות" / "App passwords").
4. בשדה שם האפליקציה ("App name") הקלד בדיוק: LIAS
זה רק תיאור שיעזור לך לזהות את הסיסמה ברשימה של Google — אפשר כל שם, אבל LIAS מומלץ כדי שתדע למה היא נוצרה. אין קשר בין השם הזה לאפליקציה עצמה, ואין צורך ב-Google Cloud / API כלשהו.
5. לחץ Create — Google יציג סיסמה של 16 אותיות (למשל abcd efgh ijkl mnop).
6. הדבק אותה בשדה למעלה ולחץ 💾 שמור. אפשר עם או בלי רווחים.
שים לב: הסיסמה מוצגת פעם אחת בלבד — אם איבדת אותה, צור חדשה (ומחק את הישנה מהרשימה).
הסיסמה נשמרת ב-Keychain של המחשב בלבד — לא בקבצים ולא ב-DB.
Outlook/Yahoo/וואלה — נתמכים גם; צור סיסמת אפליקציה של אותו ספק באותה דרך.
בשיטה המהירה ההתחברות רצה לבד; במצב SMS יופיע חלון להזנת הקוד מהטלפון.
⚠️ אימות ידני
במצב זה הדפדפן ייפתח ותצטרך להתחבר בעצמך דרך אתר gov.il — באמצעות הטלפון, ביומטרי, או כל שיטה אחרת.
לאחר ההתחברות הפורטל ייפתח אוטומטית וההורדה תתחיל — גם אם הדפדפן ייסגר אחר כך.
הסיסמה נכתבת ל-Keychain בלבד — לא נשמרת בקבצים, לא ב-DB, ולא ניתנת לצפייה חוזרת מה-UI.
בה משתמשת ההתחברות האוטומטית לפורטלים (NET + BDR).
אפשר כמה מיילים מופרדים בפסיק. כל מה שעולה לדרייב ישותף איתם אוטומטית בצפייה בלבד — בלי עריכה או תגובות. אישור יופיע כאן:
הגדרות סנכרון — לכל פורטל בנפרד
כל פורטל עצמאי. ההגדרה קובעת מה קורה בלחיצת ההורדה בלשונית "סנכרון".
היקף ההורדה נבחר במסך הסנכרון עצמו ?
בוחרים שם פורטל ← כל התיקים או תיקים מסוימים ← ואז את ההיקף (לקוחות עם תיק פתוח / רק פתוחים / הכל). הבחירה נשמרת לפעם הבאה.
